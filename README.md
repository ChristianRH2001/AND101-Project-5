Submitted by: **Christian Hernandez**

Time spent: **2.5** hours spent in total

## Summary

**Who's That Pokemon?** is an android app that displays a random Pokemon from the current amount of 1025. It open up to a display of the classic "Who's That Pokemon" eyecatcher from the ad breaks of the Pokemon anime. Then, when the user presses the button, it calls the PokeAPI to retireve a sprite, a name, and their Pokedex ID number for display.
